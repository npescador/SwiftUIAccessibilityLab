# Task Detail Example

## What You Will Learn
- Section header accessibility
- Editable fields with value announcements
- Picker labels, hints, and values
- Save/cancel feedback

## Accessibility Patterns Used
- accessibilityAddTraits(.isHeader)
- accessibilityLabel and accessibilityValue for editable fields
- accessibilityHint for pickers and actions
- Announcements on save/cancel

## Common Mistakes
- Headers without header traits
- Pickers without labels or hints
- Silent save/cancel actions

## VoiceOver Experience
Accessible version provides labeled fields and clear feedback.
Inaccessible version omits key hints and announcements.
