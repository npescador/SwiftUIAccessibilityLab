# Login Example

## What You Will Learn
- Text field accessibility labels and hints
- Secure input accessibility
- Error announcements
- Button context and state feedback

## Accessibility Patterns Used
- accessibilityLabel and accessibilityHint on form fields
- accessibilityValue for password visibility state
- UIAccessibility announcements for errors
- Clear button labels and hints

## Common Mistakes
- Using placeholders as the only labels
- Missing error announcements
- Missing context for actions

## VoiceOver Experience
Accessible version provides clear labels, hints, and error feedback.
Inaccessible version omits labels, hints, and announcements.
