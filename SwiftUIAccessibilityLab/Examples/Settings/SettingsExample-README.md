# Settings Example

## What You Will Learn
- Toggle accessibility state
- Picker labels, values, and hints
- Destructive action warnings

## Accessibility Patterns Used
- accessibilityValue for toggle state
- accessibilityAddTraits(.isHeader) for sections
- accessibilityHint for risky actions

## Common Mistakes
- Toggles without clear state feedback
- Section headers not marked as headers
- Destructive actions without warning

## VoiceOver Experience
Accessible version announces state, structure, and action impact.
Inaccessible version omits context and warnings.
