# Custom Control Example

## What You Will Learn
- Adjustable accessibility actions
- Custom accessibility values
- Gesture alternatives for custom controls

## Accessibility Patterns Used
- accessibilityAdjustableAction on custom rating
- accessibilityValue for sliders and state
- Accessibility announcements on value changes

## Common Mistakes
- Each star as a separate element
- No adjustable actions
- Color-only selection without labels

## VoiceOver Experience
Accessible version exposes a single adjustable rating and labeled color options.
Inaccessible version reads each star and gives no state feedback.
